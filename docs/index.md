# pyIrena

Python tools for small-angle scattering (SAS) data analysis. A port of the Igor Pro
[Irena](https://usaxs.xray.aps.anl.gov/software/irena) package. Includes interactive
GUI tools for fitting, modeling, data merging, and visualization of SAXS/SANS/USAXS data.

:::{admonition} Start here
New users: {doc}`getting-started/installation`, then {doc}`getting-started/quickstart`.
:::

:::{admonition} Citing pyIrena
If you use pyIrena in published work, please cite the open-access paper:

Ilavsky, J. (2026). "Irena and pyIrena: 25 years of small-angle scattering analysis for complex materials, now with an AI-ready Python successor." *J. Appl. Cryst.* **59**(6). https://doi.org/10.1107/S1600576726009647
:::
